# 📐 Coniques - Plateforme Interactive

Coniques est une plateforme interactive conçue pour l'étude, l'analyse et le tracé des équations de coniques. Cet outil permet aux étudiants et aux passionnés de mathématiques de visualiser et de manipuler des courbes géométriques complexes de manière intuitive.

## ✨ Fonctionnalités Clés

- **Tracé d'Équations** : Visualisation en temps réel des paraboles, ellipses et hyperboles.
- **Interface Épurée** : Design minimaliste et moderne axé sur le contenu mathématique.
- **Analyse Mathématique** : Outils pour l'étude détaillée des propriétés des coniques.
- **Performance Web** : Rendu fluide des graphiques pour une manipulation sans latence.

## 🛠️ Stack Technique

- **Frontend** : HTML5, CSS3, JavaScript (ES6+).
- **Moteur Graphique** : Logique de tracé personnalisée en JavaScript.
- **Typographie** : Segoe UI / Fontes système pour une clarté maximale.

## 📁 Structure du Projet

```text
graphic/
├── index.html         # Page d'accueil et présentation
├── grap.html          # Interface de tracé interactive
├── css/               # Feuilles de style
├── js/                # Logique mathématique et de rendu
└── img.png            # Illustrations et assets
```

## 🚀 Utilisation

1. Ouvrez `index.html` dans votre navigateur.
2. Cliquez sur "OUVRIR" pour accéder à l'interface de tracé.
3. Saisissez ou manipulez les paramètres des équations pour visualiser les coniques.
