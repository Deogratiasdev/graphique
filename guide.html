Projet et objectifs

Le but est de construire une application web type Desmos simplifiee pour les coniques.

  • Saisir des equations mathematiques de coniques
  • Identifier automatiquement le type de courbe
  • Afficher une representation mathematique propre
  • Tracer la courbe dans un plan cartesien
  • Fournir les proprietes geometriques associees

Coniques prises en charge

  • Cercle
  • Cercle decale
  • Parabole verticale
  • Parabole horizontale
  • Ellipse
  • Ellipse decalee
  • Hyperbole horizontale
  • Hyperbole verticale
  • Equations generales a transformer

Exemples d'equations

x^2 + y^2 = 25 (x - 2)^2 + (y + 3)^2 = 16 y = x^2 - 4x + 3 x = y^2 - 6y + 5 x^2/16 + y^2/9 = 1 ((x - 1)^2)/25 + ((y + 2)^2)/9 = 1 x^2/9 - y^2/4 = 1 y^2/16 - x^2/25 = 1 x^2 + y^2 - 4x + 6y - 12 = 0 4x^2 + 9y^2 - 16x + 18y - 11 = 0

Comment lire les formes

  • Pour un cercle, les coefficients de x^2 et y^2 sont egaux.
  • Pour une ellipse, les termes sont de meme signe mais different en valeur.
  • Pour une hyperbole, les termes x^2 et y^2 ont des signes opposes.
  • Pour une parabole, un seul terme est au carre.

Conseils d'utilisation

  • Saisis une equation simple pour obtenir un trace instantane.
  • Utilise les formes generales pour verifier la reduction canonique.
  • Sur mobile, le graphe reste prioritaire et l'interface passe en colonne.
  • Le bouton PDF ouvre la boite d'impression du navigateur pour enregistrer le guide.

Architecture

  • app.js: initialise toute l'application.
  • parser.js: interprete les equations.
  • conics.js: gere la classification et les proprietes.
  • graph.js: gere le tracage JSXGraph.
  • ui.js: gere l'interface et les interactions.

Outils recommandes

  • math.js pour les calculs et le parsing.
  • JSXGraph pour le tracage graphique.
  • MathLive pour la saisie mathematique.
  • MathJax pour l'affichage propre des formules.

Responsivite et experience utilisateur

  • Sur mobile, le layout passe en colonne avec le graphe prioritaire.
  • Sur tablette, l'interface reste hybride et confortable au toucher.
  • Sur desktop, le panneau de saisie, le graphe et les controles restent bien separes.
  • Le but est de garder une interface fluide, legere et simple a comprendre.
